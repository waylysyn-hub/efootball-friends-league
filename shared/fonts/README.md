# Cairo

`Cairo-Variable.ttf` is the unmodified variable font supplied in `Cairo.zip`, originally named `Cairo-VariableFont_slnt,wght.ttf`. It contains the full Arabic and Latin glyph sets, a weight axis from 200 to 1000, and a slant axis from -11 to 11.

The shared stylesheet loads the upright face locally with `font-display: swap`. Outfit remains the Latin display/body font; Cairo handles Arabic text. The font is distributed under the included SIL Open Font License 1.1.
